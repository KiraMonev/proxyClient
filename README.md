# Proxy Service

Сервис прокси-доступа с регистрацией и личным кабинетом.

## Запуск проекта

Проект запускается одной командой:

```bash
docker-compose up --build -d
```

После запуска будут доступны следующие сервисы:
- Frontend (Vue 3): `http://localhost:3000`
- Backend API (FastAPI): `http://localhost:8000`
- Swagger UI документация: `http://localhost:8000/docs`
- PostgreSQL: `localhost:5432`
- Redis: `localhost:6379`

### Наполнение базы тестовыми данными

Для проверки работы (подключения к прокси) в базу нужно добавить виртуальные машины. Для этого есть скрипт, который создаёт 2-е тестовые машины. Выполните его внутри запущенного контейнера backend:

```bash
docker-compose exec backend python -m app.seed
```

## Как пользоваться

### 1. Регистрация
Откройте [http://localhost:3000/register](http://localhost:3000/register), введите свой email и придумайте пароль.

### 2. Получение ключа активации
При регистрации (или при нажатии "Обновить ключ" в кабинете) генерируется ключ активации. Поскольку проект работает в режиме разработки, письма перехватываются консольным email-бэкендом (Celery).

Чтобы увидеть ключ, посмотрите логи Celery worker:
```bash
docker-compose logs -f celery
```
В логах вы увидите письмо с ключом активации (32-символьная строка).

### 3. Личный кабинет
Вы можете войти на сайт [http://localhost:3000/login](http://localhost:3000/login) и перейти в Личный кабинет. Там отображаются ваши данные, дата регистрации, и есть возможность сменить пароль или сгенерировать новый ключ.

### 4. Десктопное приложение
Для тестирования подключения к прокси-серверу используется Tkinter-приложение. Для его запуска понадобится Python.

Установка зависимостей:
```bash
cd desktop
pip install -r requirements.txt
```

Запуск:
```bash
python app.py
```

В появившемся окне введите ключ активации, полученный из логов Celery, и нажмите "Подключиться". Приложение свяжется с сервером по HTTP (для проверки ключа и получения прокси) и откроет WebSocket-соединение для отслеживания статуса в реальном времени.

Если вы остановите backend или отключитесь вручную, статус в приложении сразу обновится.
